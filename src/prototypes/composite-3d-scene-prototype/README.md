# Composite 3D scene prototype

> THROWAWAY PROTOTYPE — not production code.

This prototype answers which composed scene should become the visual production specification for QuoteGenerator's read-only 3D Visualization.

Run QuoteGenerator from the repository root:

```powershell
npm run dev
```

Open Simple Sketch and choose **Visa 3D-prototyp**, or open
`http://127.0.0.1:5173/sketch/3d-prototype` while signed in with sketch access.

The prototype is bundled as a separate Vite HTML entry so its Three.js runtime
does not become part of the main QuoteGenerator bundle.

The same representative, renderer-facing Simple Sketch is shown in two URL-controlled variants:

- `?variant=technical` — a technically neutral review scene;
- `?variant=environment` — a restrained, daylight patio context.

The plan contains several ClickitUp widths, a 1,000 mm door, a 90° corner, two free ends, three Jumbrella instances, one Fiesta heater, and two approved Simplified Product Model fallbacks. The problem summary is persistent and its rows focus the corresponding entity. Nothing is persisted and no commercial data is loaded.

The composed-scene prototype uses a dimensioned semantic proxy for the already approved ClickitUp GLB strategy and reads the Three.js installation in `C:\Users\Najk\Documents\ChatGPT\Bahama-visualizer`. It does not mutate either reference source. The proxy keeps this ticket about scene composition instead of repeating the asset-structure decision from the ClickitUp build prototype.

Use the scene-style switcher or the left/right arrow keys to compare variants. The camera presets provide perspective and top views; drag to orbit and scroll to zoom.
